# GTA5Phone — Modular Improvised Phone Hub (F6), Contacts, Wardrobe & Clothing Shops

Модуль **Д** из линейки модов — единый расширяемый **Телефон (`F6`)**, к которому остальные моды подключаются как аддоны:
- **Автоматическая интеграция аддонов через `mod_bus.hpp`**:
  - При установке `GTA5GarageAndTuning` в телефоне появляются **Механик**, **Автосалон (покупка машин онлайн)** и **Страховая**.
  - При установке `GTA5Inventory` в телефоне появляется **Еда и Броня**, а отдельная кнопка `F7` автоматически отключается.
  - При установке `GTA5AmmuNation` отображается статус **Арсенала**.
  - Сторонние моды могут регистрировать собственные приложения и контакты через `modbus::RegisterPhoneAddon()`.
- **Контакты**:
  - **Старый знакомый** — раз в 10 минут снимает до 3-х звёзд розыска (с общим КД для GTA SA COOP).
  - **Механик / Автосалон / Страховая / Скорая помощь**.
- **Игроки SA-COOP**: быстрый запуск списка игроков GTA SA COOP (`F2`, настраивается в INI).
- **Гардероб CJ и Наборы одежды**:
  - Переодевание по частям (торс, штаны, обувь, цепи, часы, очки, головные уборы, спецкостюмы) из купленной одежды.
  - До 8 сохраняемых наборов одежды с авто-надеванием (**При миссии**, **Простая игра**, **При розыске**, **Вручную**).
  - Обновлённый интерфейс всех 6 сетей магазинов одежды (Binco, ProLaps, Sub Urban, ZIP, Victim, Didier Sachs) в стиле UI Kit со статусом «Куплено» и 3D-осмотром.
